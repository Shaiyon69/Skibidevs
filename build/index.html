    Build your own

    Make an app from any website

    pake-build asks you a few questions in the terminal and builds an installer for Windows, Mac or Linux. It runs on Pake by tw93, and updates Pake to the newest version every time you run it.

    1 · Install the tools (once)

    1. Node.js 18 or newer from nodejs.org.
    2. Rust from rustup.rs.
    3. Windows: Visual Studio Build Tools with “Desktop development with C++”. Mac: run xcode-select --install. Linux: see Pake's setup notes.

    2 · Get pake-build

    One file, no install. Save it into an empty folder.

    Download pake-build.mjs

    Or from a terminal: curl -LO https://shaiyon69.github.io/Skibidevs/build/pake-build.mjs

    3 · Run it

    Open a terminal in that folder and run node pake-build.mjs. Use the arrow keys, Space and Enter. It asks for:

    1. Website, for example notion.so.
    2. Name of the app.
    3. Window size: wide, chat, large or your own.
    4. Sign-in pages: links to other sites open in your browser, so tick the sign-in buttons the site has (Google, Microsoft, Apple, Facebook, GitHub, Discord, X). Popular sites come pre-ticked.
    5. Icon: optional, it uses the site's own icon otherwise.
    6. Extras: start maximized, dark mode, tray icon, always on top and more.
    7. Version, then a summary to check before it builds.

    The first build takes a few minutes. Your installer lands in pake-apps/<Name>/.

    Good to know

    • Pake updates itself: each run checks npm and installs the newest Pake before building.
    • Apps you build are yours. They don't update themselves and have no ad blocker; our Shaiyon Apps come with both.
    • Only build apps for sites you're allowed to use, and keep their names and logos for personal use.
    • Pake is open source under GPL-3.0 by tw93. pake-build is a small helper by Skibidevs and is not part of the Pake project.
